# Cisco Catalyst 9300/9500 Show Command Reference

## Overview

This project is a practical reference for common Cisco Catalyst 9300 and 9500 switch commands used in network support, network administration, and troubleshooting.

The goal is to document what each command does, when to use it, and which details to review when diagnosing common network issues.

## Topics Covered

- System information and hardware inventory
- Interface status, counters, and errors
- VLANs, trunks, and EtherChannel
- Stacking and high availability
- Layer 2 switching and routing
- Troubleshooting and device health
- Configuration inspection
- Security and management checks
- Change and maintenance verification

## Who This Reference Is For

This reference is intended for students, entry-level network technicians, NOC analysts, and network support professionals who want a convenient overview of common Cisco switching commands.

## How to Use This Reference

Each command entry will explain:

- **Purpose:** What the command displays or checks.
- **When to use it:** Common support or troubleshooting scenarios.
- **What to inspect:** Important output fields or warning signs.
- **Operational notes:** Relevant limitations or precautions.

## Scope and Limitations

This is a documentation project, not a live network lab. Commands are presented for educational and reference purposes.

Command availability and output can vary by switch model, hardware configuration, and Cisco IOS XE software release. Always consult the documentation for the specific device and software version.

Commands that display configuration or diagnostic information may reveal sensitive details. Review output before sharing it, and never publish credentials, customer information, internal IP addressing, device identifiers, or company configuration.

Configuration-changing commands are identified separately from read-only inspection commands.

## Skills Demonstrated

- Cisco switching concepts
- Network troubleshooting methodology
- Technical documentation
- Network operations reference development
- Awareness of operational safety and information security
